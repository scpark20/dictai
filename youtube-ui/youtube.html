Browser extension setup
  1. Download DictAI Caption Bridge and unzip it.
  2. In Chrome or Edge, open Extensions → Manage extensions. Enable Developer mode → Load unpacked → choose the unzipped folder containing manifest.json.
  3. Reload DictAI in that browser. Paste a link and choose Open YouTube.
  4. On YouTube, expand the description → Show transcript. Select your caption language and leave timestamps visible. Click the DictAI extension → Send displayed transcript.

The extension reads only the displayed transcript when you click Send. It does not fetch hidden caption endpoints or copy cookies. If YouTube does not show a transcript, use a caption file below. Built-in app browsers may not support extensions.
